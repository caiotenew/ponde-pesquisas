Cópia de segurança automática

Ao salvar uma pesquisa, o sistema grava uma segunda cópia no armazenamento local do seu navegador. Assim, se o banco ficar fora do ar, você ainda pode baixar suas pesquisas e reenviá-las depois.

Importante: esta cópia fica neste computador/navegador. Evite limpar os dados do navegador antes de baixar o CSV diário.

Primeiro tentamos baixar os dados do PostgreSQL. Se o banco estiver indisponível, o sistema automaticamente usa a sua cópia local.
